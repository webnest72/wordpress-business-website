# WordPress Business Website

Fast, responsive WordPress business website demo — an Elementor-style landing page for a local business.

## What it is

A demo landing page showing the structure of a modern local business website: hero, services, why choose us, testimonials, and contact. Built as a static front-end demo of the kind of site I build in WordPress with Elementor.

## Features

- Clean, modern, mobile-friendly layout
- Hero section with a clear call to action
- Services section for a local business
- Testimonials and contact sections
- Fast loading, semantic HTML and CSS

## Tech used

HTML5, CSS3, JavaScript

## How to run it

Open `index.html` in any browser, or view the live demo on GitHub Pages: https://webnest72.github.io/wordpress-business-website/
